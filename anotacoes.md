- scale(): aumenta  o tamanho.
- rotate(): gira o elemento.
- translateY(): movimenta o elemento verticalmente.

# 2. Formulários HTML

## Elementos utilizados

- form: cria um formulário.
- label: identifica um campo.
- input: permite inserir informações.
- placeholder: apresenta uma orientação no campo.
- textarea: permite inserir textos maiores.
- button: cria um botão.
